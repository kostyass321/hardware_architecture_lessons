# Конспект по Алгебре высказываний

## 1. Алгебра высказываний

* Высказывание — повествовательное предложение, о котором можно однозначно сказать, истинно оно (1) или ложно (0). Бывают простыми и сложными.
* Простое высказывание — состоит из одного утверждения без логических операций.
* Сложное высказывание — состоит из простых, объединенных логическими операциями.

### Базовые логические операции

1. Инверсия (Отрицание, НЕ) — меняет значение на противоположное. Обозначается чертой над переменной или знаком отрицания.
2. Дизъюнкция (Логическое сложение, ИЛИ) — ложна только тогда, когда ложны оба операнда.
3. Конъюнкция (Логическое умножение, И) — истинна только тогда, когда истинны оба операнда.
4. Импликация (Следование, ЕСЛИ... ТО) — ложна только тогда, когда из истины (1) следует ложь (0).
5. Эквиваленция (Равносильность) — истинна, когда оба операнда имеют одинаковые логические значения.

### Формулы логики высказываний

* Формула логики — сложное высказывание, полученное из простых с помощью логических операций. Количество наборов значений переменных для n аргументов равно 2 в степени n.
* Тождественно истинная (тавтология) — формула, истинная при любых значениях входящих переменных.
* Тождественно ложная (противоречие) — формула, ложная при любых значениях входящих переменных.

Порядок выполнения операций: Инверсия -> Конъюнкция -> Дизъюнкция -> Импликация и Эквиваленция.

### Основные законы и равносильности

* Двойное отрицание: двойное отрицание переменной равно самой переменной.
* Коммутативность: переменные при И и ИЛИ можно менять местами.
* Ассоциативность: в однородных выражениях скобки можно расставлять любым способом.
* Дистрибутивность: законы раскрытия скобок (умножение относительно сложения и наоборот).
* Законы де Моргана: отрицание конъюнкции есть дизъюнкция отрицаний, а отрицание дизъюнкции есть конъюнкция отрицаний.
* Идемпотентность: повторение одной переменной через И или ИЛИ равно самой переменной.
* Поглощение: упрощение выражений, где одна переменная повторяется внутри и снаружи скобки.

## 2. Нормальные формы (ДНФ, КНФ, СДНФ, СКНФ)

* Элементарная конъюнкция — логическое произведение переменных или их отрицаний.
* Элементарная дизъюнкция — логическая сумма переменных или их отрицаний.
* ДНФ — логическая сумма (дизъюнкция) элементарных конъюнкций.
* КНФ — логическое произведение (конъюнкция) элементарных дизъюнкций.
* СДНФ (Совершенная ДНФ) — ДНФ, где каждое произведение содержит все переменные функции ровно по одному разу. Строится по строкам таблицы истинности, где функция равна 1.
* СКНФ (Совершенная КНФ) — КНФ, где каждая сумма содержит все переменные функции ровно по одному разу. Строится по строкам таблицы истинности, где функция равна 0.

## 3. Булевы функции и полином Жегалкина

* Булева функция — функция, аргументы и значения которой принимают только значения 0 или 1.
* Полином Жегалкина — выражение булевой функции в виде суммы по модулю два (исключающее ИЛИ) логических произведений переменных. Не содержит инверсий и обычных сложений. Каждая функция имеет только один уникальный полином.
* Линейная функция — булева функция, в полиноме Жегалкина которой нет произведений переменных между собой (все переменные стоят только в первой степени).

### Замкнутые классы и функциональная полнота (Теорема Поста)

Система функций называется функционально полной, если через нее можно выразить вообще любую другую булеву функцию.

Теорема Поста: Система полна тогда и только тогда, когда она не содержится целиком ни в одном из 5 замкнутых классов:
1. Класс T0 — функции, сохраняющие ноль (на наборе из всех нулей дают ноль).
2. Класс T1 — функции, сохраняющие единицу (на наборе из всех единиц дают единицу).
3. Класс S — самодвойственные функции (меняют свое значение на противоположное, если инвертировать все аргументы).
4. Класс M — монотонные функции (значение функции не может уменьшиться, если один из аргументов увеличился с 0 до 1).

## 4. Релейно-контактные схемы (РКС)

* Функция проводимости — булева функция, которая равна 1, если схема пропускает электрический ток, и 0, если схема разорвана.
* Последовательное соединение — на схеме контакты идут друг за другом. Соответствует логической операции И (конъюнкция). Ток идет, только если замкнуты оба контакта.
* Параллельное соединение — контакты идут параллельными ветками. Соответствует логической операции ИЛИ (дизъюнкция). Ток идет, если замкнут хотя бы один из контактов.
