## ***Задача 1***
Дано: $\overline{(X < 5)} \lor (X < 3) \land \overline{(X < 2)} \lor (X < 1)$, $X = 4$

Подставляю $X=4$:
- $X < 5 \to 4 < 5 = T \to \overline{(X < 5)} = F$
- $X < 3 \to 4 < 3 = F$
- $X < 2 \to 4 < 2 = F \to \overline{(X < 2)} = T$
- $X < 1 \to 4 < 1 = F$
- Сначала считаем конъюнкцию: $(X < 3) \land \overline{(X < 2)} = F \land T = F$
- Теперь дизъюнкции слева направо: $F \lor F = F$, потом $F \lor F = F$

Ответ: ***False***

## ***Задача 2***
Дано: L ⊥ A, l ⊥ B; A, B лежат в π; A не || B. Доказать: L ⊥ любой прямой C лежащей в π.

Рассуждаю так: если прямая перпендикулярна двум НЕпараллельным прямым в плоскости — она перпендикулярна всей плоскости (признак). Значит L ⊥ π. А если прямая перпендикулярна плоскости, она перпендикулярна любой прямой в этой плоскости. Значит L ⊥ C для любой C ⊂ π.

Ответ: ***утверждение верно***
